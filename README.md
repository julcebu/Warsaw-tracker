# Warsaw-tracker 
**Warsaw-tracker** jest projektem aplikacji ułatwiającej zwiedzanie Warszawy. Ma ona ułatwiać odkrywanie atrakcji turystycznych, usprawniać planowanie tras, a także integrować informacje dotyczące najciekawszych miejsc w stolicy.
