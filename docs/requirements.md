# Wymagania 

- System umożliwia użytkownikowi wybór punktu startowego spośród kilku ustalonych lokalizacji w Warszawie.
- System umożliwia użytkownikowi określenie preferowanych kategorii atrakcji turystycznych.
- System umożliwia użytkownikowi określenie, czy plan ma uwzględniać przerwę na posiłek.
- System umożliwia uwzględnienie przystanków przeznaczonych na odpoczynek lub skorzystanie z toalety.
- System umożliwia użytkownikowi określenie maksymalnego budżetu wycieczki.
- System umożliwia użytkownikowi określenie dostępnego czasu na wycieczkę.
- System generuje plan wycieczki na podstawie parametrów określonych przez użytkownika.
- System wyznacza trasę łączącą punkt startowy z wybranymi atrakcjami turystycznymi.
- System wyświetla przebieg wygenerowanej trasy na mapie.
