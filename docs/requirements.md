# Wymagania 

### Określenie preferencji użytkownika

- **W1** System umożliwia użytkownikowi wybór punktu startowego spośród ustalonych lokalizacji w Warszawie.
- **W2** System umożliwia użytkownikowi wybór jednej lub kilku preferowanych kategorii atrakcji turystycznych.
- **W3** System umożliwia użytkownikowi określenie, czy plan wycieczki ma uwzględniać przerwę na posiłek.
- **W4** System umożliwia użytkownikowi określenie, czy chce wyświetlać na mapie toalety publiczne.
- **W5** System umożliwia użytkownikowi określenie maksymalnego budżetu wycieczki obejmującego bilety wstępu oraz ewentualne posiłki.
- **W6** System umożliwia użytkownikowi określenie dostępnego czasu na wycieczkę.

### Generowanie planu wycieczki

- **W7** System generuje propozycję planu pieszej wycieczki po Warszawie na podstawie parametrów określonych przez użytkownika.
- **W8** System wyznacza trasę pieszą łączącą punkt startowy z wybranymi atrakcjami oraz ustala kolejność ich odwiedzania.
- **W9** System szacuje łączny czas wycieczki, uwzględniając czas przemieszczania się, odwiedzania miejsc oraz zaplanowanych przerw.
- **W10** System szacuje koszt wycieczki obejmujący bilety wstępu oraz zaplanowany posiłek.
- **W11** System uwzględnia określony przez użytkownika czas i budżet podczas generowania planu.
- **W12** System proponuje punkty gastronomiczne w pobliżu planowanej trasy, uwzględniając budżet po odliczeniu szacowanych kosztów biletów wstępu, jeśli użytkownik wybrał przerwę na posiłek.

### Prezentacja planu

- **W13** System wyświetla przebieg wygenerowanej  trasy na mapie.
- **W14** System przedstawia wygenerowany plan w formie uporządkowanej listy miejsc do odwiedzenia.
- **W15** System umożliwia użytkownikowi zapoznanie się z opisem i ciekawostkami dotyczącymi miejsc uwzględnionych w planie.
- **W16** System prezentuje szacowany łączny czas i koszt wycieczki.
- **W17** System umożliwia wyświetlenie lokalizacji punktów gastronomicznych w pobliżu proponowanej trasy, jeśli użytkownik wybrał taką opcję.
- **W18** System umożliwia wyświetlenie lokalizacji toalet publicznych w pobliżu proponowanej trasy, jeśli użytkownik wybrał taką opcję.
